CGU & Confidentialité

Dernière mise à jour : mai 2026

1. Présentation du service

Roulette DBD est un outil en ligne permettant de tirer aléatoirement un personnage du jeu Dead by Daylight parmi une sélection définie par l'utilisateur. Ce service est proposé gratuitement et sans publicité.

La connexion via Twitch est optionnelle. Elle permet d'accéder à des fonctionnalités supplémentaires : enregistrement d'un profil, pré-sélection de personnages favoris, historique de tirages et annonce du résultat dans le chat Twitch.

2. Données collectées

Nous collectons uniquement les données strictement nécessaires au fonctionnement du service :

Donnée Source Utilisation Durée
Nom d'utilisateur Twitch API Twitch (OAuth) Identification, affichage dans l'interface Session active
Avatar Twitch API Twitch (OAuth) Affichage dans le header Session active
Token d'accès Twitch API Twitch (OAuth) Envoi de messages dans le chat (mode Streamer uniquement) Session active
Personnages favoris Choix de l'utilisateur Pré-sélection lors des tirages Jusqu'à suppression
Historique des tirages Tirages effectués Affichage dans le profil (max 50 entrées) Jusqu'à suppression
Préférences (modes) Choix de l'utilisateur Mode Streamer, Mode Anonyme Jusqu'à suppression

Nous ne collectons pas : adresse e-mail, numéro de téléphone, données de paiement, localisation, ou toute autre donnée non listée ci-dessus.

3. Cookies et session

Ce site utilise un seul cookie de session (sess) strictement nécessaire au fonctionnement de l'authentification Twitch. Ce cookie :

  • N'est pas utilisé à des fins publicitaires ou de tracking
  • N'est pas partagé avec des tiers
  • Expire après 24 heures ou à la déconnexion
  • Est chiffré et signé côté serveur

Comme ce cookie est strictement nécessaire au service (sans lui, la connexion Twitch est impossible), il ne nécessite pas de consentement préalable selon le RGPD et les recommandations de la CNIL.

4. Base légale du traitement

Le traitement de vos données repose sur votre consentement explicite : vous choisissez librement de vous connecter via Twitch. Sans connexion, aucune donnée personnelle n'est collectée ou stockée.

Vous pouvez retirer ce consentement à tout moment en supprimant votre compte depuis votre page profil.

5. Vos droits (RGPD)

Conformément au Règlement Général sur la Protection des Données (RGPD), vous disposez des droits suivants :

  • Droit d'accès — vous pouvez consulter toutes vos données depuis votre page profil
  • Droit de rectification — vos favoris et préférences sont modifiables à tout moment
  • Droit à l'effacement — vous pouvez supprimer l'intégralité de vos données depuis votre profil
  • Droit à la portabilité — vos données sont affichées clairement dans l'interface
  • Droit d'opposition — vous pouvez vous déconnecter et cesser d'utiliser le service à tout moment

Pour exercer ces droits ou pour toute question, vous pouvez également contacter le responsable du service.

6. Hébergement & sécurité

Le service est hébergé sur Render (San Francisco, CA, USA) avec des serveurs situés en Europe (Frankfurt). La base de données est hébergée sur MongoDB Atlas (AWS Frankfurt).

Les données sont transmises via HTTPS. Les tokens d'accès Twitch sont stockés uniquement en session (cookie signé) et ne sont jamais écrits en base de données.
